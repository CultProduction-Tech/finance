# API показателей Культа для MCP

Подготовлено локально 16.11.2026. Не опубликовано и не развёрнуто.

`GET /api/second-brain/kpi?startDate=2026-01-01&endDate=2026-11-16`

Авторизация: `Authorization: Bearer <отдельный служебный ключ MCP>`.
Принимаются только даты, до 366 дней между ними. Юрлицо фиксировано: Cult.
Другие параметры, включая entity и snapshot, отклоняются. Без ключа, сессией
браузера или без финансового разрешения прочитать данные нельзя. POST, PUT,
PATCH и DELETE не реализованы. Ключ от cron или учётной записи не используется.

## Настройка администратором

Переменная `SECOND_BRAIN_API_CLIENTS` — JSON-массив объектов с полями:
`id` — уникальное имя интеграции, `sha256` — SHA-256 отдельного случайного
ключа, `scopes` — массив с `cult:finance:kpi:read`.

Создать ключ из 32 случайных байтов в base64url (43 символа) средствами
менеджера секретов. Исходный ключ хранится только в закрытом окружении MCP,
его SHA-256 — в окружении дашборда. Ключи не добавлять в Git или этот документ.
Без валидной конфигурации endpoint отвечает 503; неверный ключ — 401;
верный ключ без scope — 403; недопустимые даты/параметры — 400.

Этот ключ предназначен для финансового инструмента MCP. Не выдавать его
пользователям, Codex или инструментам продюсера. MCP должен авторизовать
конкретного пользователя до вызова, включая поиск и выдачу источников.
Роли на стороне MCP пока не реализованы.

## Данные

Используется существующий обработчик KPI: те же исключения проектов,
бюджеты, формулы, снимки и платёжные заморозки. При заморозке денежные
данные могут быть старше времени запроса. Сохранять и показывать syncedAt,
planFactAsOf, planFactFrozen и snapshot, а не считать fetchedAt временем
актуальности всех данных. factProfit и budgetProfit не смешивать в ответах.
При сбое источника наружу возвращается нейтральная ошибка без подробностей.
