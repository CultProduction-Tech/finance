# Чтение денежного потока для MCP

GET `/api/second-brain/cashflow`, без параметров. Тот же Bearer-ключ и настройка
SECOND_BRAIN_API_CLIENTS, что для KPI; дополнительный секрет не нужен.
MCP проверяет почту/роль owner до обращения. Маршрут жёстко выбирает Культ,
не принимает entity, snapshot или иные параметры. Cookie/cron не заменяют API-ключ.

Используется существующий обработчик графика: текущий месяц и три следующих,
баланс, fact/plan, syncedAt, snapshot, planFactFrozen/planFactAsOf сохраняются.
Формулы и первичные данные не меняются. Отчёт денег не подменяет ОПиУ.

Размещение: обычный выпуск приложения после принятия ветки. Никаких миграций
или дополнительных переменных окружения нет. Установить вместе с изменением
точного списка API в middleware. MCP-адаптер уже подготовлен отдельно.

Проверка: `node --test tests/second-brain-access.test.mjs tests/second-brain-cashflow.test.mjs`.
Проверяет ключи, запрет переопределения компании, сохранение графика и заморозки,
отсутствие утечки ошибки источника. Полную сборку Next выполнить перед выпуском.
